# Project Context — TalksApp

## Кто и зачем

**Автор:** Григорий Звягинцев — Automation QA Engineer (Python)
**Сайт:** gzvyagintsev.dev (Next.js, задеплоен на Vercel)

**TalksApp** — нативное Android-приложение, которое:
1. Является мобильной версией портфолио-сайта
2. Служит **учебной мишенью** для изучения Appium (мобильное тестирование)
3. Станет основой для доклада команде по теме «Мобильное тестирование с Appium»

---

## Контент приложения

Контент берётся из тех же JSON-файлов, что и на сайте:

**Доклады (talks.json):**
- `python-basics` — Python для автоматизатора (типы, функции, ООП)
- `grokking-algorithms` — Грокаем алгоритмы (67 слайдов + мемы)
- (и другие по мере добавления)

Каждый доклад имеет: `slug`, `title`, `date`, `duration`, `level`, `tags`, `summary`, `description`, `outline`

**Мемы (memes.json):**
- Мемы из докладов, галерея

---

## Экраны приложения (MVP)

| Экран | Описание |
|---|---|
| Splash | Лого + слоган, 2 секунды |
| Главный (Home) | Аватар, имя, слоган, кнопки навигации |
| Список докладов | Карточки докладов с фильтром по уровню |
| Детальная страница доклада | Полная информация, outline |
| Галерея мемов | Сетка картинок |
| Форма обратной связи | Имя + сообщение + кнопка (локальная, без отправки) |

---

## Appium-тесты (цель проекта)

Тесты пишутся на Python с использованием Appium.
Располагаются в папке `tests/appium/` (отдельно от Android-кода).

**Покрываемые сценарии:**
- Запуск приложения
- Навигация между экранами
- Скролл списка докладов
- Открытие детального экрана доклада
- Заполнение формы обратной связи
- Проверка текстового контента

---

## Связь с сайтом

- Дизайн вдохновлён сайтом: цвета, типографика, структура карточек
- JSON-данные синхронизируются вручную (копипаст при обновлении)
- Сетевых запросов к API сайта нет — всё локально в assets/
- Чат (Vercel AI) и капча-контакты — **не переносятся** в приложение
